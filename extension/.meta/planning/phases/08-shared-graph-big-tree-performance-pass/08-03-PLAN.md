Replace the current single-frame `deferContent` pattern with a batched requestIdleCallback hydration system. The current pattern defers text/favicon for one frame per NodeVisual (line 376-390 of NodeVisual.update). For large trees where hundreds of nodes become visible at once, this causes a single expensive follow-up frame.


2. Add a method `setGestureActive(active: boolean)` to pause/resume hydration:


3. Add `scheduleHydration()` method that uses requestIdleCallback to process batches:
```ts
private scheduleHydration() {
  if (this.hydrationIdleHandle !== null) return;
  if (this.hydrationQueue.length === 0) return;
  if (this.isGestureActive) return;

  this.hydrationIdleHandle = requestIdleCallback((deadline) => {
    this.hydrationIdleHandle = null;
    const start = performance.now();
    let processed = 0;

    while (
      this.hydrationQueue.length > 0 &&
      processed < GraphPixiRenderer.HYDRATION_BATCH_SIZE &&
      (deadline.timeRemaining() > 2 || processed === 0) // always do at least 1
    ) {
      const nodeId = this.hydrationQueue.shift()!;
      const visual = this.nodeMap.get(nodeId);
      const node = this.nodeData.get(nodeId);
      if (visual && node) {
        visual.hydrateContent();
        processed++;
      }
    }

    if (processed > 0) {
      this.needsRender = true;
      this.render();
      graphProfiler.record("deferredHydration", performance.now() - start);
    }

    if (this.hydrationQueue.length > 0) {
      this.scheduleHydration();
    }
  }, { timeout: 100 });
}
```

To achieve this, add a parameter to the NodeVisual constructor or a setter:

```ts
  this.useBatchedHydration = value;
```

Then in update(), change the deferContent block:
```ts
if (this.deferContent) {

    this.state = { ...this.state, textKey: "", tagKey: "", faviconKey: "" };

  // Large tree with batched hydration: content stays deferred until hydrateContent() is called
  // Hide content elements
```
