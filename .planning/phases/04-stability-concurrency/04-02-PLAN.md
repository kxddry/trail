**NewTabApp.tsx — STAB-06 session expired banner (per user decision: inline banner similar to sidepanel):**

1. Import `authSessionItem` from `"@shared/config/storage-items.js"` and `browser` is already imported.
2. Add state: `const [sessionExpired, setSessionExpired] = useState(false);` and `const [authBusy, setAuthBusy] = useState(false);`.
3. Add a useEffect that watches for auth session changes:
```typescript
useEffect(() => {
  let cancelled = false;
  // Check initial state
  authSessionItem.getValue().then((session) => {
    if (cancelled) return;
    if (!session || !session.accessToken) setSessionExpired(true);
  });
  // Watch for changes
  const unwatch = authSessionItem.watch((newVal) => {
    if (cancelled) return;
    if (!newVal || !newVal.accessToken) {
      setSessionExpired(true);
    } else {
      setSessionExpired(false);
    }
  });
  return () => { cancelled = true; unwatch(); };
}, []);
```
4. Add a sign-in handler that opens the account portal (newtab can't use useAuthPortalFlow because it depends on the sidepanel Zustand store and QueryClient). Instead, use a simple approach — open the account app URL in a new tab:
```typescript
const handleSignIn = useCallback(async () => {
  if (authBusy) return;
  setAuthBusy(true);
  try {
    const { getBackendConfig, initBackendConfig } = await import("@shared/config/backend.js");
    await initBackendConfig();
    const baseUrl = getBackendConfig().baseUrl;
    await browser.tabs.create({ url: `${baseUrl}/account`, active: true });
  } catch {
    // If we can't open the account page, just ignore
  } finally {
    setAuthBusy(false);
  }
}, [authBusy]);
```
