   - `testAuth`: Complete email+password auth flow. Expect: session cookie set, sync indicator appears, trees load from server
   - `testSessionExpired`: Auth, wait for expiry (or manually clear session). Expect: SessionExpiredBanner appears in sidepanel, spotlight, and newtab
   - `testSyncFail`: Auth, disconnect network, trigger sync. Expect: sync indicator shows error/offline, toast notification, data preserved locally
   - `testTreeSwitch`: Create 2+ trees, switch between them. Expect: graph re-renders, dropdown shows correct active tree, node counts match
   - `testExportImport`: Export a tree to JSON, delete it, import from JSON. Expect: tree restored with same structure, node count, tags
   - `testQuotaEviction`: Fill storage near quota (or simulate), trigger archive. Expect: toast notification about quota, stub tree visible in dropdown with explanation

**ui-interaction.test.ts** (per QA-02): Create 4 interaction stub functions:
   - `testDropdownKeyboard`: Open TreeDropdown, navigate with Arrow keys, select with Enter, dismiss with Esc. Expect: focus moves visually, selection applies, dropdown closes, focus returns to trigger
   - `testModalEscape`: Open a modal (rename/delete confirm), press Esc. Expect: modal closes, background no longer inert, focus returns to trigger element
   - `testSearchNavigation`: Open FloatingSearch (Cmd+K), type query, navigate results with Up/Down, select with Enter. Expect: keyboard hints visible, results highlight, selection navigates to node
   - `testAuthBanner`: Trigger session expiry, verify banner appears. Dismiss banner, verify it stays dismissed for session. Restart browser, verify banner reappears. Expect: persistent dismiss within session, reappears on new session

Both files end with `run()` calling all stubs and a final "passed" log line.
