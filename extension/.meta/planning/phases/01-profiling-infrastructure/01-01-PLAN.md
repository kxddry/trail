**Phase enum/type:**
```typescript
type ProfilePhase =
  | 'layout'
  | 'renderNodes'
  | 'buildConnections'
  | 'computeOffsetPositions'
  | 'setData'
  | 'updateVisible'
  | 'updateConnections';
```

**GraphProfiler class:**
- Constructor takes `windowSize: number` (default 60).
- Internal storage: `Map<ProfilePhase, number[]>` — each phase stores a circular buffer of the last `windowSize` duration samples in milliseconds.
- Use a write index per phase (not shift/unshift which is O(n)). Track `buffers: Map<ProfilePhase, { samples: Float64Array, writeIndex: number, count: number }>`. Use `Float64Array(windowSize)` for each phase, initialized lazily on first `record()` call for that phase.
- `record(phase: ProfilePhase, durationMs: number): void` — writes durationMs into the circular buffer for that phase. Advances writeIndex, wraps at windowSize.
- `getStats(phase: ProfilePhase): { p50: number, p95: number, count: number, last: number } | null` — computes percentiles from the current buffer contents. For p50/p95 computation: copy the valid portion of the buffer (first `count` samples, capped at `windowSize`), sort ascending, then `p50 = sorted[Math.floor(sorted.length * 0.5)]`, `p95 = sorted[Math.floor(sorted.length * 0.95)]`. Return null if no samples recorded for that phase.
- `getAllStats(): Record<ProfilePhase, { p50: number, p95: number, count: number, last: number } | null>` — calls getStats for all 7 phases.
- `reset(): void` — clears all buffers.

**Singleton export:**
```typescript
export const graphProfiler = new GraphProfiler();
```

**Console API:**
At module scope (executes on import):
```typescript
(window as any).__graphMetrics = () => {
  const stats = graphProfiler.getAllStats();
  // Pretty-print to console as a table
  const table: Record<string, { p50: string; p95: string; samples: number; last: string }> = {};
  for (const [phase, data] of Object.entries(stats)) {
    if (data) {
      table[phase] = {
        p50: `${data.p50.toFixed(2)}ms`,
        p95: `${data.p95.toFixed(2)}ms`,
        samples: data.count,
        last: `${data.last.toFixed(2)}ms`,
      };
    } else {
      table[phase] = { p50: '-', p95: '-', samples: 0, last: '-' };
    }
  }
  console.table(table);
  return stats;
};
```

**Timing helper (for wrapping useMemo/function calls in GraphCanvas):**
```typescript
export function profileSync<T>(phase: ProfilePhase, fn: () => T): T {
  const start = performance.now();
  const result = fn();
  graphProfiler.record(phase, performance.now() - start);
  return result;
}
```
