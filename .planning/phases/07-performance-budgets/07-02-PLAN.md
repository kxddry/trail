    **Virtualize the search results list using @tanstack/react-virtual — per PERF-04:**

    Reference SpotlightResults.tsx for the established pattern of using `useVirtualizer` in this codebase.

    1. Import `useVirtualizer` from `@tanstack/react-virtual` and `useRef` (already imported).
    2. Keep the existing `SearchResultsListProps` type and `SearchResultItem` type unchanged.
    3. In the `SearchResultsList` component:
       - Add a `parentRef = useRef<HTMLDivElement>(null)` for the scrollable container.
       - Keep the existing `items` useMemo that builds the flat SearchResultItem array.
       - Add the virtualizer:
         ```typescript
         const virtualizer = useVirtualizer({
           count: items.length,
           getScrollElement: () => parentRef.current,
           estimateSize: () => 52, // approximate row height in px
           overscan: 5,
         });
         ```
       - Replace the current `.map()` render with the virtualizer pattern:
         ```tsx
         return (
           <div
             ref={parentRef}
             className="floating-search-list"
             style={{ overflow: "auto" }}
           >
             <div
               style={{
                 height: `${virtualizer.getTotalSize()}px`,
                 width: "100%",
                 position: "relative",
               }}
             >
               {virtualizer.getVirtualItems().map((virtualRow) => {
                 const item = items[virtualRow.index];
                 if (!item) return null;
                 return (
                   <div
                     key={item.id}
                     style={{
                       position: "absolute",
                       top: 0,
                       left: 0,
                       width: "100%",
                       transform: `translateY(${virtualRow.start}px)`,
                     }}
                   >
                     <SearchResultRow
                       item={item}
                       query={query}
                       isActive={activeId === item.id}
                       onSelect={onSelect}
                     />
                   </div>
                 );
               })}
             </div>
           </div>
         );
         ```
    4. Keep `SearchResultRow` memo component unchanged.
    5. Ensure the `floating-search-list` CSS class has a defined max-height or is in a flex container that constrains height (check base.css). If the list is already in a constrained container, this should work. If not, add `maxHeight: "40vh"` to the parent div style as a safety bound.
    6. When `activeId` changes (keyboard navigation), scroll the active item into view:
       ```typescript
       useEffect(() => {
         if (activeId == null) return;
         const idx = items.findIndex((item) => item.id === activeId);
         if (idx >= 0) virtualizer.scrollToIndex(idx, { align: "auto" });
       }, [activeId, items, virtualizer]);
       ```
       Import `useEffect` (already imported as part of memo).
  </action>
