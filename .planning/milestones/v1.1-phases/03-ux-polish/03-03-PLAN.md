Create a new `template.tsx` file in `apps/account/app/(app)/`. In Next.js App Router, `template.tsx` re-mounts on every navigation (unlike `layout.tsx` which persists), making it ideal for transition animations.

```typescript
"use client";

import { motion } from "motion/react";

export default function Template({ children }: { children: React.ReactNode }) {
  return (
    <motion.div
      initial={{ opacity: 0, y: 6 }}
      animate={{ opacity: 1, y: 0 }}
      transition={{
        duration: 0.25,
        ease: [0.25, 0.1, 0.25, 1],
      }}
    >
      {children}
    </motion.div>
  );
}
```

Design decisions:
- **Fade + subtle upward slide** (opacity 0→1, y 6→0): Feels directional without being distracting. The 6px shift is barely noticeable but adds a sense of motion.
- **Duration 0.25s**: Fast enough to not impede navigation, slow enough to register.
- **Ease curve [0.25, 0.1, 0.25, 1]**: Standard ease-out curve. Content arrives and settles.
- **No exit animation**: Exit animations in template.tsx would require AnimatePresence at the layout level, which adds complexity. The instant-out / fade-in pattern feels snappy and intentional.
- **No AnimatePresence needed**: template.tsx already unmounts/remounts on navigation, so `initial` fires naturally on each route change.

Do NOT use `usePathname()` as a key — template.tsx already handles re-mounting.

**template.tsx — Motion's built-in reduced motion:**
Motion v12 automatically respects `prefers-reduced-motion` when using `useReducedMotion()`. However, the simplest approach for our case is to use Motion's `reducedMotion` prop on the component:

Update the template to detect reduced motion and skip animation:

```typescript
"use client";

import { motion, useReducedMotion } from "motion/react";

export default function Template({ children }: { children: React.ReactNode }) {
  const prefersReducedMotion = useReducedMotion();

  return (
    <motion.div
      initial={prefersReducedMotion ? false : { opacity: 0, y: 6 }}
      animate={{ opacity: 1, y: 0 }}
      transition={{
        duration: prefersReducedMotion ? 0 : 0.25,
        ease: [0.25, 0.1, 0.25, 1],
      }}
    >
      {children}
    </motion.div>
  );
}
```

When `prefersReducedMotion` is true:
- `initial={false}` skips the initial animation entirely
- `duration: 0` ensures instant render with no perceptible animation

**globals.css — no changes needed:**
The existing `@media (prefers-reduced-motion: reduce)` block in globals.css handles CSS animations. Motion handles its own reduced-motion detection via the `useReducedMotion` hook, so no CSS override is needed for the template transition.
