<objective>
Cache connection geometry by topology/layout signature and separate path highlight + preview edge from base connection rebuilds.

Purpose: Currently `buildConnections()` is called on every animation frame (both in React useMemo path and imperative tick render path), regenerating the entire `ConnectionSegment[]` array. This is the primary connection performance bottleneck. By caching base connections and only updating path/preview overlays, we eliminate redundant geometry computation during animation.

Output: GraphCanvas with cached base connections, path highlight via flag toggle, preview edge as overlay -- all keyed to staticVersion so they only rebuild on topology/layout change.
</objective>

**Step 1: Create `applyPathHighlight` helper in graph-utils.ts.**

Add a new exported function after `buildConnections`:

```typescript
export function applyPathHighlight(
  baseConnections: ConnectionSegment[],
  pathNodeIds: Set<NodeId> | null,
): ConnectionSegment[] {
  if (!pathNodeIds) return baseConnections;
  return baseConnections.map(conn => {
    const [parentId, childId] = conn.id.split('-') as [NodeId, NodeId];
    const shouldHighlight = pathNodeIds.has(parentId) && pathNodeIds.has(childId);
    return shouldHighlight !== conn.onPath
      ? { ...conn, onPath: shouldHighlight }
      : conn;
  });
}
```

This function takes cached base connections (all with `onPath: false`) and returns a new array with `onPath` toggled for path segments. It reuses existing segment objects when `onPath` is already correct (no allocation).
