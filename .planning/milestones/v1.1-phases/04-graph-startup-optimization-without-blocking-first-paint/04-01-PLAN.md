<objective>
Add a strict layout signature to the graph layout cache so cached positions are only trusted when they match the current settings state, and make the offscreen worker recompute layout immediately on settings changes.

Purpose: Without a signature, stale cached positions from different layout settings (mode, spacing, density, radial params) could be served at startup, causing a visible jump when the real layout computes. The offscreen worker currently only refetches settings on SAVE_SETTINGS but does not recompute the layout, meaning the cache remains stale until the next TREE_UPDATED.

Output: Extended CachedLayoutResult type with layoutSignature, signature-validated cache reads, and offscreen worker settings-change recomputation.
</objective>
