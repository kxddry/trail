**Part A: useBootstrap.ts** — Add timeout, auto-retry, and bootstrapStatus state.

1. Change `useBootstrap` to return a `bootstrapStatus` value. Add state via `useState`:
```typescript
type BootstrapStatus = "loading" | "degraded" | "ready";
```
Start as `"loading"`. Set to `"ready"` after critical path succeeds. Set to `"degraded"` after retry failure.

2. Wrap the critical-path `Promise.all` in a timeout race:
```typescript
const BOOTSTRAP_TIMEOUT_MS = 10_000;

function withTimeout<T>(promise: Promise<T>, ms: number): Promise<T> {
  return Promise.race([
    promise,
    new Promise<never>((_, reject) =>
      setTimeout(() => reject(new Error("Bootstrap timed out")), ms)
    ),
  ]);
}
```

3. On critical path failure (catch block):
   - First attempt: set a 5-second timer, then auto-retry once.
   - On retry failure: set `bootstrapStatus` to `"degraded"`.
   - Expose a `retryBootstrap` callback that re-runs the critical path.

Implementation pattern:
```typescript
const [bootstrapStatus, setBootstrapStatus] = useState<BootstrapStatus>("loading");
const retryRef = useRef(0);

// Inside the async IIFE:
try {
  const [settings, treeState, flags] = await withTimeout(
    Promise.all([getSettings(), getTreeState(), getFlags()]),
    BOOTSTRAP_TIMEOUT_MS,
  );
  // ... existing success logic ...
  setBootstrapStatus("ready");
} catch (error) {
  console.error("[bootstrap] Critical fetch failed:", error);
  if (retryRef.current === 0) {
    retryRef.current = 1;
    // Auto-retry after 5s
    setTimeout(() => {
      // Re-trigger effect by... we need to re-run the bootstrap
      // Use a retryCount state to trigger re-run
    }, 5000);
    return;
  }
  // Second failure — degraded
  setBootstrapStatus("degraded");
  return;
}
```

Better approach: use a `retryCount` state (`useState(0)`) in the effect dependency array. On first failure, after 5s timeout, call `setRetryCount(1)` which re-triggers the effect. On second failure (`retryCount >= 1`), set status to `"degraded"`.

Return `{ bootstrapStatus, retryBootstrap }` where `retryBootstrap` is `() => setRetryCount(c => c + 1)`.
