Что это за логика
“Тропа” — одна кривая линия (маршрут) + точки (шаги/вехи). Анимация: блик пробегает по пути и на развилках расходится по веткам, точки “загораются” по уровням (сверху вниз). 
Ствол (A→B):
  M53.23 43.64 C74.6 46.37 80.31 55.93 88.26 69.09

Развилка #1 (из B — одновременно):
  B→D: M88.26 69.09 C96.21 82.27 71.21 85.9 80.28 105.61
  B→C: M88.26 69.09 C100.23 86.44 117.51 64.44 122.32 86.44

Развилка #2 (из C — одновременно):
  C→F: M122.32 86.44 C122.29 104.7 124.23 121.71 137.5 131.58
  C→G: M122.32 86.44 C137.9 86.53 150.02 94.53 158.69 110.44

  D→E: M80.28 105.61 C92.28 112.09 98.19 122.06 99.02 134.95

Spark:
  stroke-dasharray + stroke-dashoffset (бегущий сегмент)
  задержки по “уровням”: 0ms → 520ms → 1040ms (ветки стартуют одновременно)

Glow:
  opacity + scale, с задержками (delay) для последовательности
