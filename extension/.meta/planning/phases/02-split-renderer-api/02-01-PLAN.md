**3. Implement `setStaticGraph(data: StaticGraphData)` in GraphPixiRenderer:**

This method does everything the current `setData()` does EXCEPT handling particles:
- Store `data` fields on `this.data` (update nodeWidth, nodeHeight, layoutMode, showConnections, connections)
- Clear `this.cachedCullingRect`, `this.visibleIdsCache`
- Clear `this.nodeData` and rebuild from `data.nodes`
- **Rebuild SpatialIndex**: `this.index = new SpatialIndex<NodeId>(...)` — insert all nodes
- Prune orphaned NodeVisual instances
- Call `this.invalidateAll()`
- Record timing: `graphProfiler.record('setStaticGraph', elapsed)`

```typescript
setStaticGraph(data: StaticGraphData) {
  const start = performance.now();
  this.data = { ...data, particles: this.particles };
  this.connections = data.connections;
  this.cachedCullingRect = null;
  this.visibleIdsCache = new Set();
  this.nodeData.clear();
  this.index = new SpatialIndex<NodeId>(Math.max(data.nodeWidth, data.nodeHeight) * 3);
  const ids = new Set<NodeId>();
  data.nodes.forEach((node) => {
    this.nodeData.set(node.id, node);
    ids.add(node.id);
    this.index.insert(node.id, {
      minX: node.x,
      minY: node.y,
      maxX: node.x + node.width,
      maxY: node.y + node.height,
    });
  });
  for (const [id, visual] of this.nodeMap.entries()) {
    if (!ids.has(id)) {
      visual.destroy();
      this.nodeMap.delete(id);
    }
  }
  this.invalidateAll();
  graphProfiler.record('setStaticGraph', performance.now() - start);
}
```

**4. Implement `setDynamicState(state: DynamicGraphState)` in GraphPixiRenderer:**

This is the lightweight path — updates node data and connections WITHOUT rebuilding SpatialIndex:
- Update `this.nodeData` map entries in-place (set new NodeRenderModel for each node by id)
- Update `this.connections` with new connections
- Update `this.data.showConnections`
- Do NOT touch `this.index` — SpatialIndex stays from last `setStaticGraph()` call
- Do NOT clear `this.cachedCullingRect` (viewport hasn't changed)
- Call `this.invalidateVisible()` to re-render visible nodes with new data
- Record timing: `graphProfiler.record('setDynamicState', elapsed)`

```typescript
setDynamicState(state: DynamicGraphState) {
  const start = performance.now();
  state.nodes.forEach((node) => {
    this.nodeData.set(node.id, node);
  });
  this.connections = state.connections;
  this.data = { ...this.data, showConnections: state.showConnections };
  this.invalidateVisible();
  graphProfiler.record('setDynamicState', performance.now() - start);
}
```
