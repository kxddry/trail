<objective>
Formalize the static/ephemeral state separation with a GraphSnapshot type and integrate it into the renderer pipeline.

Purpose: Phase 2 introduced StaticGraphData/DynamicGraphState as local types in GraphPixiRenderer, but they lack formalization — no version tracking, no explicit basePositions, no immutability contract. This plan creates a proper GraphSnapshot type that captures the full static graph state (topology, positions, connections, layout metadata, version) and makes it the single source of truth for static data flow.

Output: graph-snapshot.ts type file, updated GraphPixiRenderer accepting GraphSnapshot, GraphCanvas constructing snapshots.
</objective>
