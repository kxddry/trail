    Create `extension/src/apps/sidepanel/ui/hooks/useOverlayBehavior.ts` exporting `useOverlayBehavior(opts)` hook.

    **Hook signature:**
    ```typescript
    type UseOverlayBehaviorOptions = {
      open: boolean;
      onClose: () => void;
      containerRef: RefObject<HTMLElement | null>;
      triggerRef: RefObject<HTMLElement | null>;
      skipEscWhenEditing?: boolean; // default false — when true, Esc is ignored if activeElement is input/textarea
    };
    export function useOverlayBehavior(opts: UseOverlayBehaviorOptions): void;
    ```

    **Hook implementation (per D from CONTEXT.md decisions):**
    1. **Esc keydown** (capture phase): When `open` is true, call `onClose()`. If `skipEscWhenEditing` is true, check if `event.target` tagName is `input` or `textarea` and skip.
    2. **Click-outside mousedown** (capture phase): If click target is not inside `containerRef` or `triggerRef`, call `onClose()`.
    3. **Focus return**: On close (when `open` transitions from true to false), call `triggerRef.current?.focus()`. Use a ref to track previous open state.
    4. **Inert management**: When `open` becomes true, find sibling elements of `containerRef.current?.parentElement` and set `inert=""` on them (excluding the container's own wrapper). When `open` becomes false, remove `inert` from those siblings. Be careful: only set inert on siblings that don't contain the dropdown itself.

    IMPORTANT: The inert approach should be scoped to the floating-controls area. Set `inert` on the sibling `.floating-island` and `.floating-controls-left`/`.floating-controls-right` divs that are NOT the one containing the open dropdown. Use `containerRef.current?.closest('.floating-island')` to find the dropdown's own island, then iterate over other `.floating-island` elements in `.floating-controls` and set inert on them.
